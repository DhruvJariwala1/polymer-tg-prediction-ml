# Dataset

This repository does not redistribute the third-party dataset used in the project.

Download **“Extra Dataset with SMILES, Tg, PID, Polymer Class”** by *linyeping* from Kaggle:

https://www.kaggle.com/datasets/linyeping/extra-dataset-with-smilestgpidpolimers-class

Place the cleaned CSV in this folder using the filename:

```text
TgSS_enriched_cleaned.csv
```

The notebook checks both `data/TgSS_enriched_cleaned.csv` and `../data/TgSS_enriched_cleaned.csv` so it can be run from the repository root or from the notebooks directory.
